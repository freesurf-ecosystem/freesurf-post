What the X API can do

The X API can post text, media, threads, and replies. It is metered: plain posts and link posts have different costs, and reads such as analytics and deletes are billed separately. Catpix passes those costs through at cost instead of hiding them in a subscription.

Native X scheduling

X’s built-in scheduler is free and handles X-specific features. It does not cross-post to other networks, and it does not provide a general-purpose API for your own apps.

What Catpix costs

Catpix is free. There is no per-channel fee, no per-seat fee, and the API is included with an account. X is the only metered network: Catpix passes X API costs through at cost ($0.015 for a plain post, $0.20 for a post with a link). Catpix currently supports eight platforms: Bluesky, X, LinkedIn, Facebook, Instagram, Threads, TikTok, and YouTube.

Where Catpix wins

  • No per-channel or per-seat math: adding a platform does not add a new line item.
  • The API is included with an account instead of being an enterprise upgrade.
  • Open source: you can inspect the code, contribute, or self-host later.
  • Android app, while many competitors are web-only or slower on mobile.
  • X API costs passed through at cost instead of bundled into a subscription.

Where X still wins

  • X-native threads and analytics.
  • No API fees when posting manually.
  • X-specific features and formatting.
  • X-only simplicity.
  • Native notifications and audience tools.
Let's be honest about the trade-off: For X-only manual posting, the native scheduler is enough. Catpix is for people who want one calendar across networks or need an API.

Who should choose which

Choose Catpix if you want free scheduling across eight platforms and X fees at cost.

Choose native X tools if you only post to X and do not need an API.
