Upload-Post pricing

Upload-Post has a free tier with two profiles and 10 uploads per month. Basic is $24/month ($16 annual) for five profiles. Professional is $50, Advanced $147, and Business $438. Paid plans include unlimited uploads.

What Upload-Post does well

Upload-Post is built for developers. It offers a simple upload API, SDKs, FFmpeg processing, AI Shorts tooling, MCP, and white-label from the Professional plan. Platform coverage is broader than Catpix.

What Catpix costs

Catpix is free. There is no per-channel fee, no per-seat fee, and the API is included with an account. X is the only metered network: Catpix passes X API costs through at cost ($0.015 for a plain post, $0.20 for a post with a link). Catpix currently supports eight platforms: Bluesky, X, LinkedIn, Facebook, Instagram, Threads, TikTok, and YouTube.

Where Catpix wins

  • No per-channel or per-seat math: adding a platform does not add a new line item.
  • The API is included with an account instead of being an enterprise upgrade.
  • Open source: you can inspect the code, contribute, or self-host later.
  • Android app, while many competitors are web-only or slower on mobile.
  • X API costs passed through at cost instead of bundled into a subscription.

Where Upload-Post still wins

  • Developer SDKs and upload tooling.
  • FFmpeg and AI Shorts processing.
  • White-label from Professional.
  • Broader platform coverage.
  • MCP and automation integrations.
Let's be honest about the trade-off: Catpix is not a developer toolkit with FFmpeg or SDKs. If you need those, Upload-Post is the better fit.

Who should choose which

Choose Catpix if you want a free scheduler and API with a ready-made UI.

Choose Upload-Post if you need SDKs, FFmpeg, white-label, or broader platform coverage.
